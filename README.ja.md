# コミュニティAIワークスペース

**グループチャットの会話から、イベントの予定・タスク・決定事項を整理できるWebアプリを作る構想です。**

> **アイデアを公開中。ご意見・共同開発メンバーを歓迎します。** リアルタイムチャットやAIアシスタントは、まだ本番公開されていません。

## 解決したい課題

友人やコミュニティでイベントを企画すると、グループチャット、出欠確認、メモ、会費の記録などが別々になりがちです。大切な決定事項が会話の中に埋もれ、主催者が何度も同じ質問に答えたり、参加者が確定した予定を確認しにくくなったりします。

**作りたいもの：** 非公開グループで会話できるリアルタイムチャットと共有ボードを一つにまとめ、AIが必要な情報の整理を手伝うWebアプリです。最終的な決定は人が行います。

## 利用の流れ

1. **グループに参加する。** 主催者が招待リンクを作成します。参加者は名前、興味、InstagramなどのSNS、連絡方法を任意で登録し、公開範囲を選べます。
2. **チャットで相談する。** 日程・集合場所・予算・持ち物・役割などをリアルタイムに話し合います。
3. **AIに整理を依頼する。** メンバーの適切な同意を得たうえで、選択した会話から要約やタスク候補を作ります。
4. **共有ボードで確認する。** AIが作った予定・決定事項・質問などの下書きを、人が確認・修正・承認します。
5. **イベントを運営する。** チャットの基本機能が役立つと確認できたら、出欠、担当タスク、費用記録を追加します。
6. **次回につなげる。** イベントの思い出やお知らせを共有し、次の集まりを企画できるようにします。

### BBQを企画するときの例

| グループ内の会話 | AIが提案する共有ボードの項目 |
| --- | --- |
| 「土曜の午後はどう？」 | 候補日：土曜日。まだ確定していない |
| 「飲み物は持っていけるよ」 | 担当候補：飲み物の準備。本人確認が必要 |
| 「会費は一人2,000円くらい？」 | 予算案：2,000円。未承認 |
| 「集合場所はどこ？」 | 未解決の質問：集合場所 |

AIは**提案と確定事項を区別**します。人の承認なしに連絡を送る、予約する、費用を請求する、正式な決定を公開するといった行動はさせません。

## 最初に作る機能

**最初の完成目標：** 招待された2人が別々のブラウザで安全にログインし、同じグループでチャットの送受信と共有タスクの編集ができること。グループ外の人は会話を閲覧できません。その後、会話を整理した**承認待ちの下書き**をAIが作る機能を試します。

AIの最初の検証では、サーバーから **OpenAI API または Anthropic Claude API** を利用します。一般向けチャットサービスの月額契約とは別に、利用量に応じた開発者向け料金が発生します。実際の利用量が増えたら、自前で運用するオープンウェイトモデルとの比較も考えます。精度、日本語対応、応答時間、サーバー・機材・電気代、保守費を含めて判断します。**自前のAIが必ず安くなるとは限りません。**

```text
メンバーのブラウザ
       ↓
認証・グループ権限・会話の保存
       ↓
リアルタイムチャット ⇄ 共有タスクボード
       ↓
許可された会話だけをAI接続サーバーへ
       ↓
AIが提案を作成 → 人が確認・承認
       ↓
必要に応じて将来、自前モデルを比較
```

**詳しい設計：** [システム設計](docs/SYSTEM_DESIGN.ja.md)と[開発タスク](docs/BUILD_PLAN.ja.md)。

## Webサイトと事業化の考え方

既存のWebサイトで、イベント運営に役立つ記事や開発ストーリーを公開し、関心のある人に意見や試用への参加を募ることが考えられます。実際に使ってもらい、主催者の作業時間が減ったか、AIの提案が正しいか、また利用したいと思うか、運用費はいくらかを検証します。

Webサイトの広告収入と将来の有料アプリは**別のビジネスモデル**です。広告掲載には個別の審査と規約遵守が必要で、アクセス数だけでは収益を保証できません。有料サービス化には、継続的に使いたい人や支払い意思の証拠が必要です。

**詳しく：** [マーケティング・価値検証](docs/MARKETING_VALIDATION.ja.md)。

## 一緒に考えたり、作ったりしませんか？

イベント主催者、デザイナー、フロントエンド・バックエンド開発者、AI開発者、テスターの方を歓迎します。技術経験がなくても、イベント運営で困ったことを教えていただくだけで助かります。

- [開発タスクから参加できそうな作業を探す](docs/BUILD_PLAN.ja.md)
- [GitHub Issuesでアイデアや意見を共有する](https://github.com/jndbekswj875-jpg/app-collaboration-/issues)
- [参加方法を確認する](CONTRIBUTING.ja.md)

個人の連絡先、実際の非公開チャット、パスワード、決済記録などは公開リポジトリに投稿しないでください。コードのライセンスは未決定のため、本格的に開発へ参加する前に成果物の扱いを相談します。
