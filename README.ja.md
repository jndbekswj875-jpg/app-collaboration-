# コミュニティAIワークスペース

**情報を見失わず、みんなで予定を共有し、もっと気軽につながる。**

友人との集まり、個人イベント、地域コミュニティなどで使える、**無料利用を目指したAIチャット型ワークスペース**を考えています。会話のスピードや参加するタイミングが違っても、誰もが必要な情報を見つけ、同じ予定を理解できるようにしたいです。

**[English page](README.md)** · **[イベント運営で困っていることを教える](https://github.com/jndbekswj875-jpg/app-collaboration-/issues/new?template=feedback-ja.yml)**

> **現在は開発途中です。** ひとつのブラウザで動く試作品はありますが、複数人で使える本物のチャットやAIアシスタントはまだ公開していません。友人やコミュニティの個人利用向けに、無料で使えるサービスを目指しています。現在、支払いや有料登録をお願いすることはありません。

## 会話しているのに、大事な情報が伝わらない

誕生日会、旅行、趣味の集まり、勉強会、ボランティア活動、地域イベントなどを企画したことはありますか？

日程の提案はグループチャットの中、集合場所は別のメッセージ、担当者の話は何十件も前の会話にある。後から参加した人が状況を理解できず、主催者が同じ説明を何度も繰り返すこともあります。

**解決したいのは、「会話をすること」と「全員が同じ情報を理解すること」の間にあるギャップです。**

## 作りたいサービス

**グループチャット + 情報を整理する共有ボード + AIチャットボット**を一つにしたアプリです。

- **みんなで会話する。** イベントやグループ活動についてチャットで相談します。
- **必要な情報を見つける。** AIに、許可された会話の要点を整理してもらいます。
- **予定を共有する。** 日時、集合場所、決定事項、担当作業、未解決の質問を一か所で確認します。
- **後からでも追いつける。** 会話を見逃した人も、何が変更されたかをすばやく把握できます。
- **集まりを企画する。** 必要に応じて、招待や出欠確認などの機能を追加していきます。

AIが作った情報は、**人が確認・承認するまで下書き**として扱います。非公開の会話をAIに送る範囲は、参加者の適切な同意をもとに管理します。

## 開発の順番：まずチャット型ワークスペース、その後にAI主催者アシスタント

### 第1段階 — AIがなくても便利なチャット型ワークスペース

まず、友人やグループが日常のイベントを企画するときに、実際に使いたくなる基本機能を作ります。

- **非公開グループチャット：** 友人を招待し、リアルタイムで相談し、過去の会話を後から確認できる。
- **イベントの情報ページ：** 日程、集合場所、説明、変更内容を一か所にまとめる。
- **共有ボード：** 決定事項、未解決の質問、準備リスト、担当者を整理する。
- **出欠と準備状況：** 参加・未定・不参加を回答し、準備の進み具合を共有する。
- **AIなしでも利用できる：** メンバーが自分で情報を記入し、修正、確認できる。

**最初の完成目標：** 招待された2人が別々のブラウザで安全にログインし、チャットと同じ予定表を共有できること。**現在はまだ未完成です。**

### 第2段階 — 繰り返しの運営業務を減らすAIイベント主催者アシスタント

チャットと情報共有が使えるようになったら、**グループ内で利用できるAIチャットボット**を追加し、主催者の小さな作業をサポートします。

| 主催者が繰り返している作業 | AIに手伝ってほしいこと |
| --- | --- |
| 大量のチャットを読み直す | 要点や変更内容を短くまとめる |
| 同じ質問に何度も答える | 確定事項に基づいた案内文を作る |
| 準備の担当者を整理する | チェックリストと担当候補を提案する |
| 未回答の人や未決定事項を探す | 確認が必要な項目を見つける |
| リマインダーやお知らせを書く | 送信前に確認できる下書きを作る |
| 次にやることを考える | 状況に応じた次の一歩を提案する |

例えば、**「あと何を準備すればいい？」**、**「昨日から何が変わった？」**、**「未決定のことは？」**、**「未回答の人に送る案内文を考えて」**と聞けるようにしたいです。

**最終的な判断は人が行います。** AIが同意なく会話を読み込む、未確定の内容を確定する、勝手にメッセージを送る、予約や支払いを行うことは想定していません。

最初のAI版では、既存のAIモデルを安全なサーバー経由で接続し、性能を検証する方法を考えています。将来的には、イベント企画に特化したアシスタントの改善や、自前で動かすモデルとの比較もできます。**専用の学習済みAIモデルはまだ開発されていません。**

[詳しい開発ロードマップを見る](docs/APP_ROADMAP.ja.md)。

## 例えば、週末の集まりを企画するとき

| グループチャットの会話 | アプリで整理したい内容 |
| --- | --- |
| 「土曜の午後はどう？」 | 候補日：土曜日。まだ未確定 |
| 「飲み物は持っていけるよ！」 | 担当候補：飲み物。本人への確認が必要 |
| 「集合場所はどこ？」 | 未解決の質問：集合場所 |
| 「昨日の会話を見逃した！」 | 確定したことと、まだ決まっていないことの要約 |

**チャットや人とのつながりを置き換えるのではなく、みんなで企画するときの情報共有のギャップを小さくしたいと考えています。**

## あなたの意見を聞かせてください

プログラミングの知識は必要ありません。実際にイベントを企画したり、参加したりするときに**困ること・あったら便利だと思うこと**を教えてください。

1. どんなイベントやグループ活動に参加しますか？
2. 連絡、招待、予定の共有にどんなアプリを使っていますか？
3. 見落としやすい情報、何度も確認する内容はありますか？
4. AIチャット型のワークスペースに何を手伝ってほしいですか？
5. 無料の試作品ができたら、使ってみたいと思いますか？

**[困っていることや欲しい機能を伝える →](https://github.com/jndbekswj875-jpg/app-collaboration-/issues/new?template=feedback-ja.yml)**

GitHubでの投稿は公開され、通常はGitHubアカウントが必要です。**実際の非公開チャット、住所、電話番号、本人や他人の個人情報は書かないでください。**
