# コミュニティAIワークスペース

**チャット・イベント企画・告知・参加まで、一つの場所で。**

友人、サークル、地域コミュニティ、イベント主催者のために、**基本機能を無料で使えることを目指したワークスペース**を考えています。チャット、告知ページ、出欠確認、チケット販売サイトを行き来せず、意見交換と最新情報の共有を一つの場所で進めたいです。

**[English version](README.md)** · **[イベント運営について意見を送る](https://github.com/jndbekswj875-jpg/app-collaboration-/issues/new?template=feedback-ja.yml)**

> **現在は開発途中です。** 一つのブラウザ内の試作品はありますが、本物の複数人チャット、チケット販売・決済、AIアシスタントは**まだ公開していません**。

## 作りたいサービス

**最初にチャット型ワークスペースを作る：** 安全なグループチャット、イベントページ、共有タスク、決定事項、主催者と参加者の直接連絡、出欠、リアルタイムの更新情報。AIなしでも無料のコミュニティイベントを企画できるようにします。

**その後、チケット販売を追加する：** イベントに応じて無料参加または有料チケットを選択し、枚数管理、決済、入場確認をまとめます。決済は信頼できる外部事業者を利用し、価格、返金規則、個人情報を適切に扱う計画です。

**さらにAIイベント主催者・マーケティングアシスタントを追加する：** 会話の要約、未解決の質問、準備タスク、参加者からのよくある質問、告知文、リマインダーの下書きをAIが提案します。公開や送信などの重要な行動は、人が確認・承認します。

### 利用イメージ

週末のコミュニティイベントを開催するとき、タイトル・日時・場所を設定し、一つのリンクを共有します。参加者と相談し、質問に答え、出欠を確認し、有料イベントならチケットを販売します。将来的には、AIが未解決の事項や変更内容を整理し、主催者向けのお知らせ文を下書きします。AIが勝手に送信するわけではありません。

## AI開発の方針

**最初は既存のAIモデルで検証**します。OpenAIやAnthropic Claudeなどの開発者向けAPIを安全なサーバーから接続し、日本語・英語で正確さ、使いやすさ、費用を比較します。将来的には、**自前で運用するモデルやイベント運営向けに調整したAI**を評価したいと考えています。独自の学習済みモデルがすでに存在するわけではありません。

**基本となる考え方：** チャットで情報共有のギャップを減らし、イベントの業務を一元化し、AIで繰り返しの作業を軽くすることです。
