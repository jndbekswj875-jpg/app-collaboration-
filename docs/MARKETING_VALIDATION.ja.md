# イベントを企画する人の声から考える

[English version](MARKETING_VALIDATION.md) · [プロジェクト概要](../README.ja.md)

コミュニティAIワークスペースは、**個人やコミュニティが無料で利用できることを目指すサービス**です。この資料では、利用者の困りごとを知り、チャット型の共有スペースが本当に役立つかを検証します。有料プランや採用の案内ではありません。

## 聞いてみたいこと

1. **誰が困っていますか？** 友人、家族、サークル、地域の主催者、勉強会、スポーツチーム、ボランティアなど。
2. **どこで情報が失われますか？** 流れの速いチャット、別々の出欠表、変更した予定、見落とした連絡、担当が分からない作業など。
3. **どんな影響がありますか？** 同じ説明の繰り返し、決定事項の見落とし、主催者の負担、遅刻、参加しにくさなど。
4. **どんな機能が助けになりますか？** チャット、共有ボード、予定の要約、AIへの質問、出欠の確認など。
5. **安心して使える条件は何ですか？** 招待、公開範囲、プライバシー、スマホでの操作、AIの正確さなど。

## アイデアを試す方法

- 実際のイベントを一つ思い出してもらい、困った場面を聞きます。
- 非公開チャットを収集せず、共通する課題を整理します。
- 試作品を見てもらい、ひとつのブラウザ内でしか動かないことも伝えます。
- 便利そうな機能だけでなく、実際に何が解決できるかを確認します。
- 安全な複数人チャットが完成したら、希望する小グループでテストします。
- 見落とし、確認の手間、予定の理解、繰り返し利用したいかを確かめます。

## 改善の手がかり

| 段階 | 確認したいこと |
| --- | --- |
| 関心 | 実際に困っている人から意見が集まるか |
| 課題 | 同じ困りごとが複数のイベントで起きるか |
| 試作品 | 画面の目的や操作が分かりやすいか |
| 実際の利用 | グループが本物の集まりのために使うか |
| 価値 | 同じ説明や連絡の見落としが減るか |
| 継続 | 次のイベントでも無料で使いたいか |
| 安心 | 同意・修正・プライバシーが守られるか |

架空の利用者数を発表したり、デモの会話を実際の利用者の声として扱ったりしません。
