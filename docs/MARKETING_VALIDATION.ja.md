# イベントを企画する人の声から考える

[English version](MARKETING_VALIDATION.md) · [プロジェクト概要](../README.ja.md)

コミュニティAIワークスペースは、**個人やコミュニティが無料で利用できることを目指すサービス**です。この資料では、利用者の困りごとを知り、チャット型の共有スペースが本当に役立つかを検証します。有料プランや採用の案内ではありません。

## このアプリ自体をイベントの告知・参加者との連絡の中心にする

このサービスは単なるチャットや準備用ツールではなく、**イベントの告知から参加者との情報共有までをまとめる場所**にもなります。主催者がイベントを作成し、リンクを共有し、興味のある人を案内し、参加者の質問に直接回答し、変更を一か所で伝えることを目指します。

**参加者の流れ：** イベント名と説明を見る → 日時・場所・参加方法を確認する → 出欠や参加希望を伝える → 質問する → 最新のお知らせを見る → 参加する → 必要なら感想を伝える。

**主催者の流れ：** イベントを作る → 適切な既存の連絡手段でリンクを共有する → 関心や出欠を確認する → 質問に回答する → 正しい変更内容を投稿する → 準備を管理する → フィードバックを確認する。

一般に公開するイベント情報と、参加者だけの非公開チャットは分けます。一つにまとめるだけで自動的に集客できるわけではありません。実際に見てもらうための告知方法や、イベントの対象者を考える必要があります。外部SNSへの自動投稿、電話、メール、広告連携は現在未実装です。

### 利用者に確認したいこと

- 前回のイベント運営では、いくつのアプリを使いましたか？
- 参加者はどこでイベントを知りましたか？
- 同じ質問への回答や変更連絡を何回繰り返しましたか？
- 集合場所や時間の変更を見落とした人はいましたか？
- イベントページと直接チャットが一つになると便利ですか？
- どんな通知なら必要だと思いますか？

**検証したいこと：** アプリ間の移動、同じ質問の繰り返し、出欠の分かりにくさ、更新の見落としが減るか、次のイベントでも使いたいと思うか。実測された成果ではなく、これから検証する仮説です。

## 無料イベントと有料チケット、AIによる告知支援

このマーケティング機能には**二つの役割**があります。

1. 主催者が公開イベントページを共有し、興味のある人や参加者と同じ場所で連絡する。無料イベントならチケット購入は必要ありません。
2. 主催者が**有料イベント**を選んだ場合、同じページでチケット種類や安全な購入方法を提供する。閲覧、関心、出欠、実際の支払いを区別して確認します。

**確認したい流れ：** イベントリンクの閲覧 → 内容の理解 → 質問・出欠 → 必要なら購入 → 支払いを確認したチケット発行 → 受付 → フィードバック。興味があるだけの人や未払いの注文を売上として数えません。

**AIによる告知支援：** 確定情報を使って紹介文、よくある質問、お知らせの下書きを作り、人が承認して利用します。同意なく大量の連絡を送ったり、非公開チャット・購入情報を使って個人を勝手に分析・対象設定したりしません。

**料金の区別：** コミュニティの基本利用は無料を目指します。イベントのチケット料金、決済手数料、将来のアプリ手数料、返金、税金、振込条件などは別に確認して明示する必要があります。現在、実際の販売や料金体系はありません。

## 聞いてみたいこと

1. **誰が困っていますか？** 友人、家族、サークル、地域の主催者、勉強会、スポーツチーム、ボランティアなど。
2. **どこで情報が失われますか？** 流れの速いチャット、別々の出欠表、変更した予定、見落とした連絡、担当が分からない作業など。
3. **どんな影響がありますか？** 同じ説明の繰り返し、決定事項の見落とし、主催者の負担、遅刻、参加しにくさなど。
4. **どんな機能が助けになりますか？** チャット、共有ボード、予定の要約、AIへの質問、出欠の確認など。
5. **安心して使える条件は何ですか？** 招待、公開範囲、プライバシー、スマホでの操作、AIの正確さなど。

## アイデアを試す方法

- 実際のイベントを一つ思い出してもらい、困った場面を聞きます。
- 非公開チャットを収集せず、共通する課題を整理します。
- 試作品を見てもらい、ひとつのブラウザ内でしか動かないことも伝えます。
- 便利そうな機能だけでなく、実際に何が解決できるかを確認します。
- 安全な複数人チャットが完成したら、希望する小グループでテストします。
- 見落とし、確認の手間、予定の理解、繰り返し利用したいかを確かめます。

## 改善の手がかり

| 段階 | 確認したいこと |
| --- | --- |
| 関心 | 実際に困っている人から意見が集まるか |
| 課題 | 同じ困りごとが複数のイベントで起きるか |
| 試作品 | 画面の目的や操作が分かりやすいか |
| 実際の利用 | グループが本物の集まりのために使うか |
| 価値 | 同じ説明や連絡の見落としが減るか |
| 継続 | 次のイベントでも無料で使いたいか |
| 安心 | 同意・修正・プライバシーが守られるか |

架空の利用者数を発表したり、デモの会話を実際の利用者の声として扱ったりしません。
