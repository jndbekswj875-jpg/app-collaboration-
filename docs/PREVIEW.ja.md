# 独自ドメインがなくても試作品を表示できます

[English version](PREVIEW.md)

現在のアプリは、**ブラウザ一つの中だけで動く静的な試作品**です。本物の複数人チャット用サーバーはまだ作っていません。GitHubの機能で、コードを書きながら画面を確認したり、試作品を公開したりできます。

## 方法1：GitHub Codespaces（開発中の確認向け）

1. [リポジトリ](https://github.com/jndbekswj875-jpg/app-collaboration-)を開きます。
2. **Code → Codespaces → Create codespace on main**を選びます。利用可能かどうかはアカウントによります。
3. ターミナルで `npm start` を実行します。
4. **PORTS**のタブから、ポート**4173**のプレビューを開きます。
5. プレビューURLの末尾に `/app/` を追加すると、チャットの画面を確認できます。コードを変更したら画面を更新します。

このリポジトリには、ポート4173を転送するための開発環境設定があります。Codespacesのプレビューは作業環境が起動している間だけ利用でき、使用量の制限がある場合があります。

## 方法2：GitHub Pages（友達に共有するプレビュー向け）

公開用の静的なファイルを追加しています。
- 英語ページ：`/index.html`
- 日本語ページ：`/ja/index.html`
- 操作できる試作品：`/app/index.html`

独自ドメインを使わずに公開する手順は次の通りです。

1. リポジトリの**Settings → Pages**を開きます。
2. **Build and deployment**で**Deploy from a branch**を選びます。
3. ブランチを**main**、フォルダを**/(root)**にして**Save**します。
4. GitHubの公開処理が成功してから、**Settings → Pagesに表示される公開URL**を使います。

通常の公開先では、各ページの末尾が `/app-collaboration-/`、`/app-collaboration-/ja/`、`/app-collaboration-/app/` になります。ただし、**公開成功が確認できるまでURLが利用できるとは限りません**。

GitHub Pagesは静的ページの公開機能です。ユーザー認証、共有データベース、リアルタイムチャット、本物のAI接続を自動で追加するものではありません。

## 現在の制限

- 試作品のデータは使っているブラウザ内だけに保存されます。
- 他の人とチャットの内容を共有することはできません。
- AIのような提案はキーワード判定のみで、本物のAIではありません。
- 個人情報や非公開の会話を入力しないでください。
- 意見の投稿は公開GitHub Issueで、通常はログインが必要です。
