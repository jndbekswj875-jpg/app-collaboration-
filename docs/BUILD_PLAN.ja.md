# 開発タスク一覧

**英語版：** [English development tasks](BUILD_PLAN.md)  
**目的：** 共同開発に関心がある人が、取り組める作業を具体的に理解できるようにする資料です。担当者・報酬・作業日程が決まっているわけではありません。

## 最初の完成目標：チャットを先に作る

招待された2人が非公開グループでリアルタイムにチャットでき、共有ボードにタスクを作成・編集できること。招待されていない人は会話を閲覧できません。その後、AIが下書きを提案して人が承認する機能を小さく試します。

## 準備：実際の課題と設計を確認する

| ID | 作業内容 | 完了条件 |
| --- | --- | --- |
| P-01 | 実際のイベント主催者に前回の運営方法と困りごとを聞く | 個人情報を除いた手順と反復する課題を一つ記録 |
| P-02 | グループ→チャット→共有ボードのスマホ画面を設計する | 招待・同意を含む3～4画面のラフ案 |
| P-03 | 認証・データベース・リアルタイム配信・運用方法を比較する | 費用・安全性・保守性を含む選定メモ |

## 第1段階：リアルタイムチャット

| ID | 作業内容 | 完了条件 |
| --- | --- | --- |
| C-01 | ログイン・招待・グループ画面を作る | スマホとPCで操作でき、エラーが分かる |
| C-02 | 認証、グループ参加権限、招待リンクを作る | サーバーが未参加者のアクセスを拒否する |
| C-03 | メッセージを保存してリアルタイム配信する | 別々のブラウザで同期し、更新後も履歴が残る |
| C-04 | チャット履歴、入力欄、時刻、読み込み・エラー表示を作る | バックエンドと接続した画面で送受信できる |
| C-05 | 不正アクセス、迷惑投稿、入力、スマホの動作をテストする | テスト結果を記録し、重大な情報漏えいがない |

## 第2段階：共有ボード

| ID | 作業内容 | 完了条件 |
| --- | --- | --- |
| B-01 | タスク・決定事項・未解決の質問を表示・編集する | 権限のある全員で変更内容を共有できる |
| B-02 | 提案中・意見が分かれている・確定済みを区別する | 下書きを正式な決定と間違えない |
| B-03 | 同時編集と権限を確認する | 変更が重なったときの動作を記録する |

## 第3段階：AI APIの試験導入

| ID | 作業内容 | 完了条件 |
| --- | --- | --- |
| A-01 | OpenAI APIまたはClaude APIをサーバーから接続する | AIサービスを切替可能で、APIキーを公開しない |
| A-02 | 同意画面と対象メッセージの選択を作る | 拒否しても通常のチャットを使い続けられる |
| A-03 | タスク・決定事項・質問の下書きを作る | 人が修正・承認・却下できる |
| A-04 | 架空または許可済みの会話10～20件で検証する | 誤り、捏造、日英の精度、確認時間、費用を記録 |
| A-05 | 呼び出し制限、利用額、障害時の処理を作る | AIの上限到達時もチャットは正常に動く |

## 第4段階：イベントとコミュニティ

| ID | 作業内容 | 完了条件 |
| --- | --- | --- |
| E-01 | イベント情報と参加・未定・不参加の出欠を管理する | 回答の変更ができ、人数が正しい |
| E-02 | プロフィール、SNSリンク、公開範囲を設定する | 非公開の連絡先が他人に見えない |
| E-03 | 会費・費用の記録を作る（決済機能なし） | 合計金額と確認状態が正しい |
| E-04 | 投稿・写真・次回イベントの機能を検討する | 本当に使いたい人がいることを確認してから作る |

## 第5段階：自前AIとの比較

| ID | 作業内容 | 完了条件 |
| --- | --- | --- |
| L-01 | AI APIの実際の使用量と有用な要約1件の費用を測る | トークン・支出の実測データ |
| L-02 | ライセンスを確認した自前モデルで同じテストを行う | 精度・応答時間・サーバー代・保守費の比較 |
| L-03 | 外部API・自前AI・併用から選ぶ | 品質と総費用に基づく判断 |

## 作業の進め方

```text
P-01、P-02、P-03
        ↓
C-01、C-02 → C-03 → C-04 → C-05
        ↓
B-01 → B-02 → B-03
        ↓
A-01、A-02 → A-03 → A-04、A-05
        ↓
必要性に応じてE-01～E-04
        ↓
費用が増えたらL-01 → L-02 → L-03
```

画面のデザインや試作は先行できますが、認証と閲覧権限をテストするまでは、実際の参加者の非公開情報を入れないでください。

## 参加するには

[GitHub Issues](https://github.com/jndbekswj875-jpg/app-collaboration-/issues)で、興味のある**作業IDを一つ**選び、できそうなことや疑問をコメントしてください。大きな作業を始める前に、実装範囲、確認方法、コードのライセンス、成果物の扱いを相談します。実際の非公開チャットやAPIキーは投稿しないでください。

**最初の受け入れ条件：** 2人で安全にチャットができ、共有タスクが同期し、外部の人は閲覧できないこと。AIの提案は人が承認するまで下書きのままです。
