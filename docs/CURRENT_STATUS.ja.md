# 現在の開発状況

**確認日：** 2026年10月22日
**開発段階：** v0.1 — ブラウザ内だけで動く試作品。本番サービスではありません。

[English version](CURRENT_STATUS.md)

## コードで動く機能

| 機能 | 状態 |
| --- | --- |
| Webアプリの画面 | コードを追加済み |
| グループの選択・作成 | 同じブラウザの中だけで利用可能 |
| チャットの送信・履歴表示 | 同じブラウザ内の試作品。複数人でのリアルタイム通信は未実装 |
| ページ更新後の保存 | ブラウザ内のローカルストレージ |
| 手動の共有タスクボード | 同じブラウザ内の試作品 |
| ボード用の下書き提案 | キーワード判定のみ。実際のAIではない |
| イベントの出欠回答 | 同じブラウザ内だけ |
| 任意のプロフィール | 同じブラウザ内だけ |
| プログラムの単体テスト | テストコードを追加済み |
| 自動チェック | GitHub Actionsの設定を追加済み |

## まだできていない機能

- 本物のユーザー登録とログイン、サーバー側の認証。
- 実際の招待リンクやグループ参加権限の管理。
- サーバーと共有データベース、複数人のリアルタイムチャット。
- 複数人で同期するボード、出欠、プロフィール。
- OpenAI API、Claude API、自前AIモデルとの接続。
- AIへの送信同意、運営・削除などの本番向け仕組み。
- 決済サービスや会費の送金。
- 本番Webサイトへの公開と運用。

**安全上の注意：** 現段階ではデモ用データしか扱えません。個人情報や非公開の会話は入力せず、安全なグループチャットとして利用しないでください。

- [ ] 実際に公開・共有できるイベントページ。
- [ ] 本物のイベントで使える無料参加登録・出欠確認。

- [ ] 返金、手数料、販売者の規約、売上の確認。

- [ ] 実測を使った自前モデル・自前運用AIとの比較。

**注意：** 現在のAI風の機能は単純なキーワード判定のみです。決済や課金はできず、本物の参加者情報も使用していません。[詳しいロードマップ](APP_ROADMAP.ja.md)


## 手元で試す方法

リポジトリのルートフォルダから、以下を実行します。

    npm run check
    python3 -m http.server 4173

ブラウザで http://localhost:4173/app/ を開きます。これはローカルの静的ページ配信であり、実際のチャットサーバーではありません。

グループの切り替え、チャット送信、タスク追加、疑似的な提案、承認、ページ更新後の保存、初期データへのリセットを確認できます。

## 本物のチャットとして完成する条件

別々のブラウザから、認証された2人が同じグループでリアルタイムにメッセージを送受信でき、サーバーに履歴が残ること。参加していない第三者は、サーバーを直接操作してもメッセージを閲覧・送信できないこと。v0.1ではまだ達成していません。

## GitHubで一緒に開発する方法

1. 作業したいIssueを一つ選びます。
2. ブランチまたはフォークを作成します。
3. 必要なコードを変更し、テストを追加します。
4. 自動チェックとブラウザでの動作確認を行います。
5. Issue番号と確認結果を記載したプルリクエストを作ります。
6. レビューが終わり、検査に合格した変更だけをメインブランチへ取り込みます。
